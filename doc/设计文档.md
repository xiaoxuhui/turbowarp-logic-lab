# 设计 v0.1.0

状态：PENDING。模型与原生项目生成、SVG 造型、浏览器测试分层。

Stage 全局列表 T/A/B/Q 各 24 项：类型 0 空/1 输入/2 NAND/3 NOT/4 AND/5 OR/6 输出；端口存 1-based 来源格号，0 悬空。Q 存单比特值。U_T/U_A/U_B/U_Q 为最近编辑快照。拓扑不允许循环；候选连接先从来源向其依赖传播可达标记，若可达目标则拒绝，原数据不变。24 遍扫描足以解析任意最长 24 节点 DAG，与格号无关。

一个格子角色克隆 24 次，每个持有本地格号。一个隐藏控制器执行事务、求值及用画笔画正交折线，网格角色负责显示 0/1。画笔层在角色后方，交叉线不导通。模式按钮高亮，选择来源加亮。触控采用两次点击而非精细拖线。单线程忙碌锁防止并发编辑，广播重绘后释放。

JS 参考求值器仅用于验证；运行时所有求值和交互均为可编辑 Scratch 积木。浏览器测试读取 VM 列表并以独立递归求值器逐节点断言；所有主要交互使用真实鼠标。保存重载检查结构与行为。复用本地 Node、JSZip 和既有 Playwright，保留 Chromium 沙箱。
