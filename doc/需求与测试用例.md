# 逻辑小实验室 v0.1.0

状态：PENDING。2026-10-21 用户授权在 TurboWarp 模仿逻辑工坊，独立作品，不改原项目。

固定 6×4 网格、单比特组合逻辑，输入开关、NAND、NOT、AND、OR、输出灯。原生 Scratch 积木与画笔扩展，无远程代码。输入立即传播；悬空输入为 0。禁止组合反馈。一个端口一个来源，替换连线；来源允许扇出。两输入门上半格为 A，下半格为 B。

操作：左边选元件，点空格放置；搭建模式点输入翻转。连线模式依次点来源和目标上/下半格；再次点来源取消。移动模式依次点元件、空格，引用随位置迁移。删除模式点击元件并清理所有引用。撤销最近一次电路编辑。清空须 3 秒内再次点击。示例按钮还原双输入 NAND。绿旗启动时保留已有电路，取消未完成操作。保存通过编辑器文件菜单或自动化 VM 导出完整 SB3。

U01 原生项目合法、24 格、六种元件与模式指示；U02 四组 NAND 真值；U03 NOT/AND/OR 全真值；U04 空板手动放置及 A/B 连线；U05 扇出和端口替换；U06 拒绝反馈/无输出来源/空目标；U07 移动保留全部引用，空移动及占用不破坏电路；U08 删除清线及单步撤销；U09 清空确认/取消与撤销；U10 示范、绿旗重启、保存重载保留电路；U11 24 格上限及长链/反向编号传播；U12 桌面与窄屏真实输入、无 VM 编译异常。

本版不包含无限画布、总线、延迟寄存器、自定义门封装、三维模式、原站存档导入或自动保存到浏览器。
