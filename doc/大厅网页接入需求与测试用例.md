# 逻辑小实验室：大厅网页接入需求与测试用例

2026-10-26 用户授权实施。复用现有原生 SB3、6×4 网格和画笔扩展，不重新开发电路游戏，不制作独立 APK。

- 保持放置、连线、移动、删除、单步撤销、反馈拒绝和示例语义。
- 网页包含完整离线运行时，触摸使用现有点选来源/目标操作；保留原始 SB3 与编辑器工作流。
- 用 turbowarp-logic-lab. 前缀自动保存完整空闲电路。重进恢复 T/A/B/Q、撤销快照及必要状态，未完成点击操作不作为新存档覆盖完整电路。
- 错误/损坏存档保留原字节并明确提示，不清空其它游戏；网页产物独立输出 web-dist/。
- 源仓库保持私有，大厅只分发带正确许可和固定源身份的运行资源。
